CHURCH DEVICE CONTROL 0.3 — SETUP

DOWNLOADS
Church-TV-Control.exe: standalone portable app; no installation required.
Church-Device-Control-Setup.exe: installer with per-user and all-users options.
Church-TV-Control.zip: portable app plus instructions and source.
The EXE filename stays the same for existing shortcuts.

INSTALLATION
Choose "Install for me only" for no administrator requirement. Choose the
all-users option for Program Files; Windows will request elevation if needed.
Select optional desktop and Start menu shortcuts. Windows controls taskbar
pinning: the optional helper shows a shortcut after setup; right-click it and
choose Pin to taskbar (Show more options may be required). It cannot silently
pin a taskbar icon. Close running copies before upgrading. Uninstall preserves
your per-user settings. Installing to Program Files does not share settings
or credentials between Windows users; configure sync separately for each user.

MIGRATION AND ROOMS
Your current device/"room" names remain device names. We cannot infer whether
"Lobby (Cafe)" means a device or a room, so room assignments start blank.
Select a device, edit Device name and Room, then Save device. Devices with the
same room name belong together. To control a room, select a member or enter
its room name, then use Room ON or Room OFF and confirm. Names match without
case sensitivity. To move a device, change Room and save. A room disappears
when no devices are assigned. All devices controls the entire list.
The list scrolls horizontally and vertically when needed.

KASA
Open Settings and enter the TP-Link/Kasa account email and password. Save local
settings before Discover devices or Add Kasa. Credentials are encrypted with
Windows DPAPI for the current user and are never copied to another PC.
Configure credentials on each installation that will control Kasa devices.
Enable third-party/local access in the TP-Link app if your firmware requires it.
Supported protocols: legacy XOR on TCP 9999 and authenticated KLAP v1/v2 over
local HTTP port 80. Other authentication protocols are not supported yet.
Only single-outlet smart plugs are supported; multi-outlet strips are rejected.
Firmware support varies, so test one plug first. Errors appear in the result
column/message; try entering the plug IP manually if discovery misses it.
The plug state means its relay is on/off, not the power state of the appliance
connected to it. Use the Roku row to read a TV's screen state.
Room commands can affect connected appliances; check membership before use.

SETTINGS SYNC
1. On the first PC, Settings > Generate key > Save local settings.
2. Copy that key to Settings > LAN sync key on each other PC and save.
3. Allow Church Device Control through Windows Firewall on the trusted Private
   network. Local IT may need to allow inbound/outbound UDP 45439. Per-user
   installation does not bypass firewall policy or grant network permissions.
4. Keep the apps open. Sync + refresh starts an exchange immediately. Each app
   also exchanges settings and checks status once a minute. A listener accepts
   authenticated settings in the background; only one copy per Windows session
   should run. Closing the app stops sync and refresh.
5. Confirm room assignments/names appear on the other PC, then test a change
   in the opposite direction before relying on it during a service.
Broadcast discovery works on the same LAN/subnet. Routed VLANs and isolated
Wi-Fi need network changes; this version has no cross-subnet peer address UI.
The shared key protects settings with authenticated AES-GCM encryption. Treat
it as a secret; anyone with it on the LAN can edit the shared device settings.
No power commands are sent through sync. Each PC controls devices directly.
Names, IPs, types, serials, rooms, timestamps and deletion markers sync.
Credentials, keys and observed power states do not sync. Different device edits
merge; newest timestamp wins for the same device. Keep Windows clocks accurate.
A deleted device stays deleted when older copies rejoin. To restore it, use
Add Roku or Add Kasa by IP; rediscovery alone does not undo a deletion.
If a PC is offline, it retains its local list and catches up once reconnected.

FILES
%APPDATA%\ChurchRoku\tvs.json: local device settings and sync metadata.
%APPDATA%\ChurchRoku\tvs-v0.2-backup.json: preserved old-format list.
%APPDATA%\ChurchRoku\local-secrets.bin: DPAPI-protected local credentials/key.
Do not run older versions concurrently: they do not understand the new format.

0.3.1: KLAP setup-account mode is tried automatically after a normal account
authentication mismatch. Keep your normal TP-Link credentials in Settings.
